# Dylux — GitHub Website

Website tĩnh cho Dylux, tối ưu để triển khai trên GitHub Pages.

## Bản sửa ảnh
- Toàn bộ ảnh giao diện đều được đóng gói local trong `assets/`.
- Catalog có 22 sản phẩm và 3 ảnh local cho mỗi sản phẩm trong `assets/products/` (66 file WebP).
- Không phụ thuộc ảnh Dyson CDN cho giao diện.
- Các ảnh nguồn ban đầu do người dùng cung cấp được lưu trong `assets/prompt/`.
- Gallery sản phẩm có thumbnail + ảnh lớn, không còn hotlink ảnh sản phẩm từ website bên ngoài.

## Chức năng
- Danh mục sản phẩm
- Lọc và sắp xếp
- Chi tiết sản phẩm, thông số, công nghệ
- Gallery 3 ảnh local / sản phẩm
- Yêu thích
- Giỏ hàng
- Form liên hệ
- Hỗ trợ khách hàng qua Facebook Dylux
- Responsive desktop/mobile
- Animation nhẹ
