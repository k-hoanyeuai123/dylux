# Dylux — Dyson storefront

Website frontend tĩnh được nâng cấp từ file HTML bạn cung cấp.

## Có sẵn
- Catalog theo nhóm: máy hút bụi, chăm sóc tóc, lọc không khí/quạt, wet & dry/robot.
- Tìm kiếm sản phẩm, bộ lọc, sắp xếp.
- Giỏ hàng + localStorage.
- Wishlist + localStorage.
- So sánh tối đa 3 sản phẩm.
- Quick view / modal chi tiết.
- Checkout demo lưu yêu cầu đơn hàng vào localStorage.
- Quiz tư vấn sản phẩm.
- FAQ accordion.
- Gallery sử dụng các hình ảnh bạn đã đưa trong prompt.
- Responsive mobile/tablet/desktop.

## GitHub Pages
1. Tạo repository mới.
2. Upload toàn bộ thư mục này, giữ nguyên `index.html` và thư mục `assets/`.
3. Vào **Settings → Pages → Deploy from branch → main / root**.
4. Mở URL GitHub Pages được cấp.

## Lưu ý quan trọng khi đưa vào kinh doanh thật
- GitHub Pages chỉ là frontend tĩnh; checkout hiện là demo, chưa thu tiền thật.
- Nên nối backend/CMS và cổng thanh toán riêng trước khi nhận đơn.
- Catalog hiện tham chiếu các sản phẩm/dòng sản phẩm đang hiển thị trên Dyson Việt Nam tại thời điểm cập nhật; giá và tồn kho có thể thay đổi. Nút **Xem Dyson** dẫn về nguồn chính thức.
- Chỉ sử dụng tuyên bố “nhà phân phối chính hãng/được ủy quyền” trên website nếu doanh nghiệp có giấy tờ/thoả thuận xác nhận quyền sử dụng tuyên bố đó.
- Kiểm tra quyền sử dụng hình ảnh, logo và tài sản thương hiệu trước khi quảng bá thương mại.
